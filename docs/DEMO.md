# AllinOneForensics guided demo

The demo is a safe, read-only walkthrough for people who are new to DFIR. It uses synthetic data and does not read local cases, accept uploads, or send evidence to a third party.

## Try it locally

```bash
python -m pip install -e ".[dev]"
uvicorn aiof.web.app:app --host 127.0.0.1 --port 8088
```

Open `http://127.0.0.1:8088/demo`. Select **Listen to overview** for browser-local narration. The voice is generated by the browser's Web Speech API; no audio or page content is uploaded.

## Guided lesson

1. **Preserve** — Evidence is copied into a case and hashed with SHA-256. Work from forensic copies, not originals.
2. **Parse** — Platform parsers turn logs, browser artifacts, email, memory, and cloud exports into normalized findings.
3. **Correlate** — IOC matching, Sigma logic, and MITRE ATT&CK mapping connect individual observations into an investigation story.
4. **Report** — Review the unified timeline, chain of custody, findings, and generated HTML/DOCX/PDF reports.

The demo's JSON is available at `/api/v1/demo`. The service health endpoint is `/healthz`.

## Run a real local case

```bash
aiof case create --name "Incident-001" --examiner "Analyst"
aiof ingest Incident-001 ./evidence-copy
aiof parse Incident-001 --all
aiof report Incident-001 --format html,docx,pdf
aiof ui
```

Use `http://127.0.0.1:8088` for the operational dashboard. The `/demo` page is separate and never displays local case data.

## Safety and deployment

- Keep the operational API on a private network or behind authentication and TLS.
- Do not expose sensitive evidence or case directories to a public host.
- The included Render configuration runs the synthetic demo mode and health endpoint. Set `AIOF_DEMO_ONLY=true` for a public sample deployment.
- UAC, IRIS, Volatility, YARA, and other external tools are optional integrations. Install only the tools required by your authorized investigation and follow their official documentation.
- This project is for authorized forensic and incident-response work.
