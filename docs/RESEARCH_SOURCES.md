# Research Sources and References

## Official Repositories & Documentation Sources

1. **Awesome Incident Response**
   - URL: https://github.com/meirwah/awesome-incident-response
   - Purpose: Curated list of incident response resources, tools, and frameworks.
   - Status: Active / Community Maintained.

2. **Volatility 3**
   - URL: https://github.com/volatilityfoundation/volatility3
   - Purpose: Advanced memory forensics framework.
   - License: Volatility Software License (VSL) / Python Software Foundation License.

3. **The Sleuth Kit (TSK)**
   - URL: https://github.com/sleuthkit/sleuthkit
   - Purpose: Digital investigation and file system analysis library/tools.
   - License: CPL 1.0 / GPLv2.

4. **Plaso (log2timeline)**
   - URL: https://github.com/log2timeline/plaso
   - Purpose: Extract timelines from forensic artifacts.
   - License: Apache 2.0.

5. **Hayabusa**
   - URL: https://github.com/Yamato-Security/hayabusa
   - Purpose: Windows event log fast timeline and threat hunting.
   - License: MIT.

6. **Chainsaw**
   - URL: https://github.com/WithSecureLabs/chainsaw
   - Purpose: Rapid Windows EVTX forensic analysis and Sigma hunting.
   - License: AGPL-3.0.

7. **Sigma**
   - URL: https://github.com/SigmaHQ/sigma
   - Purpose: Generic signature format for SIEM/log analysis.
   - License: MIT / Detection Rule License.

8. **ALEAPP / iLEAPP**
   - URL: https://github.com/abrignoni/ALEAPP / https://github.com/abrignoni/iLEAPP
   - Purpose: Android/iOS logs and event and protection parser.
   - License: MIT.

9. **Capa**
   - URL: https://github.com/mandiant/capa

   - License: Apache 2.0.

10. **Zeek & Suricata**
    - URLs: https://github.com/zeek/zeek, https://github.com/OISF/suricata
